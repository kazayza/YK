# 📋 موجز المشروع (Project Brief) — YKCoatings

## التعريف
**YK Coatings ERP** — نظام تخطيط موارد مؤسسات ويب متكامل لمصنع **واي كي كوتينج** (طلاءات ودهانات)، مبني بتقنية **Blazor Server (.NET 8)** مع قاعدة بيانات **SQL Server**، واجهة عربية RTL بالكامل.

- **اسم المشروع الكودي:** `YKCoatings` (كان سابقاً `DizurdeWeb` — تمت إعادة التسمية الكاملة في 17/09/2026)
- **الملفات الرئيسية:** `YKCoatings.sln` / `YKCoatings.csproj`
- **المساحة الاسمية:** `YKCoatings` وبداخلها `YKCoatings.Services` / `YKCoatings.Models` / `YKCoatings.Helpers` / `YKCoatings.Components`

## الأهداف
1. إدارة كاملة لدورة الشراء: طلب شراء ← أمر شراء ← استلام ← فاتورة ← مرتجع.
2. إدارة المخازن والمخزون: أرصدة، حركات، تحويلات، جرد.
3. إدارة التصنيع: وصفات (BOM)، أوامر إنتاج، صرف خامات، تشغيلات إنتاج، تصنيع بالقطع (Contract Manufacturing).
4. الموارد البشرية: موظفين، أقسام، حضور، إجازات، سلف، جزاءات، مسير مرتبات.
5. الحسابات الأساسية: عملات، شروط دفع، قوائم أسعار (قيد التطوير: القيود اليومية، دليل الحسابات).
6. الأمان: مستخدمين، أدوار وصلاحيات دقيقة (عرض/إضافة/تعديل/حذف/طباعة/تصدير/اعتماد/ترحيل/إلغاء)، سجل تدقيق، سجل دخول، إدارة جلسات.

## نطاق الحالي
- 105 صفحة Razor (في `Components/Pages`)، 51 ملف خدمة، 26 ملف DTO — تشمل الآن: **مبيعات** (فواتير + أوامر) · **خزينة (Gold Edition)** · **حسابات (Gold Edition Pro)** إلى جانب الأساس (مشتريات/مخازن/تصنيع/موارد بشرية).
- قاعدة البيانات سحابية (SQL Server عبر الإنترنت) — السكيما تُدار على الخادم مباشرة (لا توجد Migrations داخل المستودع).

## خارج النطاق حالياً
- المبيعات المتبقية: عروض أسعار (`SCR_QUOT`) ومرتجعات بيع (`SCR_SRET`) — (الفواتير وأوامر البيع منفذة).
- الحسابات المتبقية: إقفال يومي (`SCR_DAILYCLOSE`) وبطاقة تكلفة (`SCR_COSTCARD`).
- ضبط الجودة (`SCR_QC`).
- النسخ الاحتياطي من داخل النظام.
