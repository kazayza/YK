# 🏭 سياق المنتج (Product Context) — YK Coatings ERP

## لماذا هذا النظام؟
مصنع واي كي كوتينج يحتاج نظاماً واحداً يربط المشتريات بالمخازن والتصنيع والموارد البشرية بدلاً من ملفات Excel المتفرقة، مع صلاحيات دقيقة وتتبع كامل لكل عملية (Audit Log).

## المستخدمون
| الدور | الاستخدام الأساسي |
|---|---|
| مدير النظام (Admin) | كل شيء: المستخدمون، الأدوار، الإعدادات، السجلات |
| المحاسب | فواتير الشراء والبيع، القيود والخزينة والسندات، العملات، شروط الدفع، التقارير المالية |
| أمين المخزن | أذون الاستلام، التحويلات، الجرد، أرصدة المخزون |
| مسؤول المشتريات | طلبات وأوامر الشراء، الموردين، مقارنة الأسعار |
| مسؤول الإنتاج | وصفات BOM، أوامر الإنتاج، التشغيلات، صرف الخامات |
| الموارد البشرية | الموظفين، الحضور، الإجازات، السلف، المرتبات |
| الموظف العادي | عرض بياناته، طلبات الإجازة، كشوف المرتب |

## الوحدات الوظيفية (كما تظهر في القائمة الجانبية)
- **البيانات الأساسية:** أصناف، تصنيفات، وحدات، مخازن، موردون، عملاء، عملات، شروط دفع، قوائم أسعار، إعدادات.
- **المشتريات:** طلبات شراء، أوامر شراء، أذون استلام، فواتير شراء، مرتجعات شراء.
- **التصنيع:** وصفات تصنيع، أوامر إنتاج، صرف خامات، تشغيلات إنتاج، تصنيع بالقطع، عنصر إنتاج حالي (Widget).
- **المخازن:** أرصدة، حركات، تحويلات، جرد.
- **المبيعات (Gold Edition):** فواتير بيع (قائمة/إضافة/تعديل/عرض) + أوامر بيع اختيارية («الفاتورة هي الأساس — نفس نظام المشتريات») — عروض الأسعار ومرتجعات البيع لم تُنفَّذ بعد.
- **الخزينة (Gold Edition):** خزائن وبنوك · كشف خزينة · تحويلات نقدية · حسابات بنكية · سندات قبض وصرف · مصروفات · شيكات · لوحة خزينة (رصيد لحظي + قيد أوتوماتيك).
- **الحسابات (Gold Edition Pro):** شجرة حسابات (عرضان: شجري/تفصيلي) · قيود يومية · ميزان مراجعة · دفتر أستاذ · سنوات مالية · مراكز تكلفة.
- **الموارد البشرية:** أقسام، مسميات، موظفون، حضور وانصراف، إجازات (أنواع/طلبات/أرصدة)، أيام العطل، سلف، جزاءات، مسير مرتبات (تفاصيل + كشف مرتب).
- **إدارة النظام:** مستخدمون، أدوار وصلاحيات، سجل العمليات، سجل الدخول.

## تجربة الاستخدام (UX)
- **اللغة:** عربية بالكامل، اتجاه RTL — خط **Tajawal** الأساسي (من `yk-theme-gold.css`) مع Cairo احتياطي.
- **الثيم:** Gold & Black Premium — ذهبي `#D4AF37` + أسود فاخر، شعارات PNG ذهبية، أيقونات SVG inline (بدون إيموجي).
- **القائمة الجانبية:** داكنة (كحلي)، قابلة للطي، موديولات ديناميكية حسب صلاحيات المستخدم مع تجميع أب/أبناء.
- **الشريط العلوي:** عنوان الصفحة + إشعارات حية (تحديث كل 30 ثانية بصوت) + التاريخ + شارة الدور + خروج.
- **الجلسة:** تحذير قبل الخروج التلقائي عند الخمول (30 دقيقة افتراضياً) + إجبار تغيير كلمة المرور عند أول دخول/انتهاء الصلاحية.
- **الطباعة:** معظم القوائم لديها زر طباعة/تصدير Excel (ClosedXML) وتقارير تنفتح في نافذة مطبوعة منسقة بشعار النظام.
