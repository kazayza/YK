# 📚 بنك الذاكرة — YK Coatings ERP

> **الهدف:** هذا المجلد هو "الذاكرة الدائمة" للمشروع. أي مساعد ذكي (Cline أو غيره) يجب أن يقرأ هذه الملفات في بداية كل جلسة قبل أي تعديل، ليفهم المشروع بسرعة ويعمل بنفس الأنماط الموجودة.

## ملفات البنك

| الملف | المحتوى | متى تقرأه |
|---|---|---|
| `projectbrief.md` | تعريف المشروع، الأهداف، النطاق | دائماً — أول ملف |
| `productContext.md` | المستخدمون، الوحدات الوظيفية، تجربة الاستخدام | عند العمل على ميزات/صفحات |
| `techContext.md` | التقنيات، البنية، قاعدة البيانات، الأوامر | عند كتابة أي كود |
| `systemPatterns.md` | الأنماط المعمارية المتبعة (الخدمات، DTO، الصلاحيات، الطباعة) | قبل إنشاء أي ملف جديد |
| `activeContext.md` | السياق الحالي: آخر تغييرات وما يجري الآن | دائماً |
| `progress.md` | سجل الإنجازات وما تبقى | لمعرفة حالة المشروع |

## قواعد الاستخدام

1. **اقرأ قبل أن تكتب:** لا تعديل بدون فهم النمط الموجود في `systemPatterns.md`.
2. **حدّث بعد أن تنجز:** بعد أي مهمة كبيرة حدّث `activeContext.md` و`progress.md`.
3. **اللغة:** توثيق المشروع ومحتوى الواجهة بالعربية، أسماء الكود بالإنجليزية.
4. **الهوية:** اسم النظام الرسمي **YK Coatings** (كودياً: `YKCoatings`) — لا استخدم الاسم القديم Dizurde إطلاقاً.
