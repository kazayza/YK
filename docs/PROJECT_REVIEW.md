## 2. 🔴 مخاطر عالية (يجب المعالجة)

### 2.1 تجزئة كلمة المرور بـ SHA-256 بدون Salt
`AuthService.HashPassword` يستخدم SHA-256 مجرداً — قابل للـ Rainbow Tables.
**التوصية:** الترحيل إلى `Rfc2898DeriveBytes` (PBKDF2) أو `BCrypt.Net`، مع عمود Salt وكتابة هجين يقبل الهاش القديم ويحدثه عند أول دخول ناجح.

### 2.2 سر قاعدة البيانات في appsettings.json
كلمة مرور SQL Server ظاهرة في المستودع.
**التوصية:** `dotnet user-secrets` للتطوير + متغيرات بيئة/Key Vault للإنتاج، وتدوير كلمة المرور فوراً لأنها أصبحت مكشوفة في النسخ السابقة.

### 2.3 لا يوجد حد أقصى لحجم الصفحات أو Pagination على مستوى SQL
القوائم تجلب كل الصفوف (`WHERE IsActive = 1` فقط) — ستتراجع الأداء مع نمو البيانات.
**التوصية:** إضافة `OFFSET / FETCH` مع معاملات `@PageIndex, @PageSize` وعدّاد `COUNT(*)` في القوائم الكبيرة (Items, StockMovements, AuditLog, LoginHistory).

## 3. 🟠 مخاطر متوسطة

| # | الملاحظة | التوصية |
|---|---|---|
| 3.1 | `<style>` مكرر داخل كل صفحة (~40 صفحة تكرر نفس أنماط البطاقات) | الاعتماد على `yk-theme.css` الجديد وتخفيف CSS الصفحات تدريجياً |
| 3.2 | `auth.js` غير محمّل في App.razor لكنه موجود (localStorage `yk_user` القديم `dez_user`) | حذفه أو تحميله إذا كان مستخدماً |
| 3.3 | `Timer` في MainLayout ينادي `LoadNotifications` من خيط خلفي مع `StateHasChanged` — خطر race مع circuit | استخدام `PeriodicTimer` داخل حلقة async أو تمرير عبر `InvokeAsync` (موجود جزئياً) |
| 3.4 | عدم وجود توقيت UTC موحد — `GETDATE()` و`DateTime.Now` مختلطان | توحيد على `SYSDATETIME()`/UTC + تحويل للعرض |
| 3.5 | صور الشعار PNG القديم (2MB logo.png) لا يزال في wwwroot | حذف الملفات القديمة غير المستخدمة لتخفيف الحجم |
| 3.6 | لا يوجد file upload validation واضح في صفحات الصور (ImagePath) | التحقق من الامتداد/الحجم وحفظ خارج wwwroot الافتراضي |

## 4. 🟡 تحسينات منخفضة الخطورة

- صفحات القالب الافتراضي (`Counter`, `Weather`, `Home`) غير مستخدمة — تُحذف.
- `auth.js` و`sounds/notification.mp3` قد يكونان بلا استخدام فعلي (الصوت يولّد WebAudio).
- إضافة `HealthChecks` (`AddHealthChecks().AddSqlServer(...)`) لمراقبة الاتصال.
- إضافة `app.UseResponseCompression()` لملفات CSS/JS.
- توحيد رسائل الخطأ للعرض للمستخدم بدل catch الفارغ `{ }` المنتشر (يبتلع أخطاء حقيقية) — سجّلها على الأقل في `Console.Error` أو ILogger.

## 5. 📌 ملاحظة معمارية مهمة
**غياب طبقة تكامل قاعدة بيانات مدارة:** لا Migrations ولا سكربتات سكيما في المستودع — أي فقدان للخادم يعني فقدان تعريف البيانات. يُوصى بإضافة مجلد `database/` يحوي سكربتات إنشاء كل الجداول + بيانات التهيئة، وتحديثه مع كل تغيير.

## 6. خطة المعالجة المقترحة (حسب الأولوية)
1. **الآن:** user-secrets + تدوير كلمة مرور DB + حذف publish/ القديم.
2. **الأسبوع القادم:** Pagination للقوائم الكبيرة + ترحيل الهاش إلى PBKDF2 هجين.
3. **الشهر القادم:** توحيد الطبقات على yk-theme + مجلد database/ + حذف الملفات الميتة.
